# 雨夜便利店街角 · 微缩立体模型（三渲二）

一座可以自由拖拽、旋转、缩放观看的**微缩三维立体模型**：正方形底座上搭出一处日式便利店的雨夜街角，
整体呈现出「小巧、精致、可收藏」的模型感。画面为**三渲二（赛璐璐 / 卡通渲染）**风格，
强调清晰的轮廓线、干净的材质层次、暖色室内灯光与冷色雨夜街景的对比。
画面中**没有任何 UI 界面元素** —— 只有场景本身。

```
拖拽 = 旋转      滚轮 / 双指 = 缩放      右键拖拽 = 平移
（静置时相机会缓慢自动环绕，一旦操作即停止）
```

---

## 运行方式

产出是**纯静态**页面，不需要安装依赖、不需要构建：

```bash
# 任选一种本地静态服务器（必须用 HTTP 打开，file:// 会被浏览器的模块 CORS 拦住）
python3 -m http.server 5199 --bind 127.0.0.1
# 然后访问 http://127.0.0.1:5199/index.html
```

`bench.json` 已按 `static` 形态写好，Studio 会直接托管整个产出目录。

浏览器要求：支持 WebGL2 与 `importmap` 的现代浏览器（Chrome / Edge / Safari 16+）。

- **完整正方形底座** 48 × 48，底部带模型切面质感与深色压边框，顶面有微弱网格刻度。
- 主路（东西向）沿南侧，横街（南北向）沿西侧，二者在**西南街角**交汇 —— 明确的街角转折感。
- 主路北侧人行道、横街东侧人行道、巷道人行道，均带路缘石与压边。
- 路面：中心虚线、边线、停止线、**反光斑马线**、菱形预告标、车道导向箭头、停车位划线。

## 基础动效（让模型“活着”，但保持克制）

| 动效 | 实现 |
|---|---|
| 持续降雨 | 4200 个拉丝雨滴的 `Points` + 自定义 Shader，随风倾斜、跟随相机循环下落 |
| 屋檐 / 落水管滴水 | 雨棚外沿与落水管处的滚动水滴贴图，透明度随时间脉动 |
| 地面积水涟漪 | 全局共享的 14 个涟漪 uniform，被积水上的涟漪层着色器采样，扩散圆环 + 波动 |
| 招牌 / 灯箱轻微闪烁 | 主招牌、竖招牌、入口灯箱的正弦闪烁 + 偶发「灯管打嗝」 |
| 自动门偶尔开合 | 17 秒周期，平滑开合 + 门机轻微抖动 |
| 雨水沿玻璃滑落 | 玻璃雨痕贴图 UV 缓慢下移，玻璃透明度轻微呼吸 |
| 路面积水反射灯光 | CubeCamera 环境探针 → PMREM 环境贴图；湿地面用 `MeshPhysicalMaterial` 反射霓虹与店内暖光 |
| 远处信号灯微弱变化 | 车行信号红/黄/绿 12 秒循环，行人信号与之错开，带轻微频闪 |

## 技术要点

- **三渲二**：`MeshToonMaterial` + 5 级阶梯 `gradientMap`，色阶分明、无写实高光；
  另加**反向外壳描边**（背面 + 法线方向外扩的自定义 Shader，按几何尺寸自适应粗细）得到清晰的日式动画轮廓线。
- **湿地面反射**：`CubeCamera` 在街角高度拍一张环境立方体贴图，
  经 `PMREMGenerator` 处理后交给湿地面材质；积水则用 `MeshPhysicalMaterial`
  （低粗糙度 + 水面法线贴图）直接反射街景。
- **后期处理自建**（不依赖 `UnrealBloomPass`，后者在部分软件渲染器上会输出全黑）：
  场景 → 线性 HDR 缓冲 → 亮部软阈值提取 → 半分辨率双向高斯模糊两轮 → 泛光叠加 +
  ACES 色调映射 + 暗部偏冷/亮部偏暖调色 + 饱和度/对比度 + 暗角 + 胶片颗粒 → sRGB 输出。
- **性能**：商品等大量重复小物件用 `InstancedMesh` 批处理；几何与贴图全部缓存复用；
  全场景约 1160 个对象、约 1.9 万三角面、19 个光源、1 个粒子系统。
- **零外部资源**：所有贴图（招牌文字、海报、杂志封面、商品标签、雨痕、水面法线、路面标线……）
  都由 Canvas 2D 现场绘制，three.js 也已随包放在 `vendor/`，完全离线可用。

## 开发期辅助参数（不影响默认画面）

在 URL 后追加查询参数可固定机位、便于逐角度审阅或排查：

| 参数 | 作用 |
|---|---|
| `?cam=x,y,z` | 指定相机位置 |
| `?target=x,y,z` | 指定观察目标 |
| `?fov=36` | 指定视场角 |
| `?shot=1` | 关闭自动环绕（截图用） |
| `?plain=1` | 绕过后期链直接渲染 |
| `?nohemi=1` `?nokey=1` `?nofill=1` `?nospill=1` `?noenv=1` `?noint=1` `?noemis=1` | 分别关闭半球光 / 主光 / 补光 / 门口溢出光 / 环境反射 / 店内灯光 / 自发光 |
