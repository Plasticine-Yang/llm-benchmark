# 星見町、雨の交差点

雨夜里的日式便利店街角微缩景观。场景完全由 Three.js、程序化几何与 Canvas 2D 贴图生成，没有使用 Blender，也没有任何外部模型、图片或在线资源。

## 打开方式

直接双击 `index.html` 即可；也可以通过静态服务器访问：

```bash
python3 -m http.server 8000
# 浏览器打开 http://127.0.0.1:8000/
```

页面是纯画布体验，没有可见 UI / 操作提示。拖拽（单指）旋转，滚轮 / 双指缩放观察。相机被约束在模型上方，避免穿入地面。

## 场景内容

- 12 × 12 的完整正方形收藏底座，黄铜铭牌与包边。
- 转角便利店：玻璃幕墙、自动滑门、发光招牌、玻璃雨棚、入口地垫、灯箱与海报。
- 店外：自动贩卖机、自行车、雨伞架、垃圾分类桶、路灯、电线杆与电线、路牌、护栏、停车位、排水沟、斑马线、倒影积水、小巷入口、空调外机、公告栏、行人信号灯。
- 店内：整齐的饮料冷柜、零食 / 日用品货架、便当与饭团冷藏柜、冰淇淋冰柜、杂志架、收银台、热食柜、关东煮、咖啡机、后场门、储物柜、天花灯箱、地面导视与大量商品陈列。
- 动态：持续降雨、屋檐滴水、玻璃水痕、地面积水波纹、招牌轻微闪烁、自动门开合、关东煮与咖啡蒸汽、雨棚下灯串、旗帜轻摆、远处信号灯变化。

## 技术

- Three.js `MeshToonMaterial` + `OutlineEffect` 的三渲二外观。
- 自写 instanced rain shader，店内区域被排除在降雨之外。
- 所有招牌、包装、海报、地砖、柏油、水面涟漪均由 Canvas 程序化绘制。
- 湿润路面使用程序化环境贴图、积水反射贴片与动态雨滴扩散环。
- 桌面 1440×900、2× DPR 下测试约 60 FPS。

## 文件

- `index.html` — 页面入口与无 UI 视觉叠层。
- `bundle.js` — 已构建的独立运行脚本。
- `src/` — 可读源码。
- `preview.png` — 默认视角预览图。
- `tools/build.mjs` — 重新打包脚本（`pnpm install && node tools/build.mjs`）。
- `THIRD_PARTY_NOTICES.md` — Three.js MIT 许可。
