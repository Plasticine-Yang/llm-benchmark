# 雨夜のコンビニ · Rainy Night Konbini Diorama

一个用 Three.js 从零搭建的日式雨夜便利店街角微缩模型（三渲二 / 卡通渲染），全程不使用 Blender 或任何外部模型资源；所有几何体、贴图（招牌、海报、地面、商品）都由代码程序化生成。

## 打开方式

- **直接打开**：双击 `dist/index.html`（单文件，已内联所有代码，无需服务器、无需联网）。
- 开发模式：`npm install && npm run dev`，然后访问 http://127.0.0.1:5188
- 重新构建：`npm run build`

## 操作

| 操作 | 效果 |
|---|---|
| 左键拖拽 | 旋转 |
| 滚轮 / 双指捏合 | 缩放 |
| 右键拖拽 / 双指拖动 | 平移 |

界面上没有任何 UI 元素。截图调试可加 URL 参数 `?view=front|side|top|close|inside|back`。

## 内容

- **底座**：14×14 正方形，木质展示台 + 黄铜边条 + 铭牌，侧面露出沥青 / 碎石 / 土层剖面。
- **便利店（视觉中心）**：招牌（含闪烁）、转角大玻璃窗、自动门（周期开合 + 感应灯）、雨棚、门口地垫、雨伞架、垃圾分类桶、自动贩卖机 ×2、立柱招牌、幡旗。
- **店内**：两组货架（零食 / 杯面 / 日用品）、7 门饮料冷柜、便当 / 饭团 / 三明治冷藏柜、收银台与 POS、热食柜、关东煮（含蒸汽）、自助咖啡机、杂志架、冰柜、ATM、烟柜、后场门、菜单灯箱、吊牌、地面导视（排队脚印、箭头）、橱窗海报。
- **街角**：十字路口与转角、斑马线、停车位、排水沟（水流动画）、雨水箅子、井盖、积水、路灯（含光锥）、电线杆与电线、变压器、路牌 / 止まれ标志 / 町名牌、护栏、车挡柱、凸面镜、红绿灯与行人灯、公交站牌、小巷入口、空调外机、垃圾站、公告栏、邻家香烟店与二层住宅、熟睡的猫。

## 动效

持续降雨、地面雨滴飞溅、屋檐滴水和落点涟漪、积水波纹、玻璃上的雨滴滑落、湿地面实时反射（积水处清晰，其余处为纵向拉长的模糊反射）、招牌 / 灯箱闪烁、自动门开合、红绿灯循环、行人灯闪烁、幡旗飘动、空调风扇转动、关东煮蒸汽、小巷壁灯偶尔闪烁。

## 渲染

`MeshToonMaterial` 三阶色调 + 基于法线 / 深度的屏幕空间描边 + 平面反射 + Bloom + 冷暗部 / 暖高光调色与暗角。

## 目录

- `src/`：场景源码（`main.js` 渲染管线，`shop.js` 便利店，`street.js` 街道道具，`ground.js` 地面与底座，`rain.js` 雨，`materials.js` 自定义着色器，`textures.js` 程序化贴图）
- `dist/index.html`：构建产物
- `tools/`：无头浏览器截图与交互验证脚本
- `screenshots/`：验证截图
